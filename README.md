# Commuto

Commuto is a web-based cab sharing and ride booking system developed using Java, JSP, Servlets, and MySQL.  
The platform allows drivers to post rides and passengers to search and book rides easily.

## Features
- User Registration & Login
- Ride Posting
- Ride Search
- Ride Booking
- Driver & Passenger Dashboard
- MySQL Database Connectivity

## Technologies Used
- Java
- JSP & Servlets
- HTML
- CSS
- MySQL
- GlassFish Server
- NetBeans IDE

## Project Objective
To provide a smart, affordable, and efficient ride-sharing platform for daily commuters.
