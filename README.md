## 📖 About

Commuto is a web application that connects **drivers** and **passengers** on one ride-sharing platform. Drivers can post trips with available seats and fares, while passengers can search and book rides easily.

---

## ✨ Features

- User registration & login (Driver / Passenger roles)
- Post rides with source, destination, seats & fare
- Search rides by source & destination
- Book rides with fare splitting
- Driver ride request approval (accept / reject)
- Booking history & dashboards for both roles

## 🚀 Getting Started

### Prerequisites
- JDK 8+
- Apache NetBeans IDE
- GlassFish 5+ or Apache Tomcat
- MySQL Server 8.x

### Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/ananyajain327/Commuto---The-cab-sharing-system.git
   cd Commuto---The-cab-sharing-system/Commuto
   ```
2. Import the database by running [`database.sql`](./database.sql) in MySQL Workbench.
3. Set your MySQL username/password via environment variables (`DB_USER`, `DB_PASSWORD`) — see [`.env.example`](./.env.example).
4. Open the project in NetBeans, clean & build, then deploy to GlassFish and run.
5. Visit `http://localhost:8080/Commuto/`
